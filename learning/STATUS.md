## 当前真实数据流

- 首页：App.vue的load_accounts → fetch('/accounts') → Vite5173代理到FastAPI8001 → read_live_account()调用read_paper_account()并组实盘字典 → Vue/组件显示。模拟账户基本资料五项已来自数据库，但返回尚缺快照和持仓；实盘仍写死。
- 快照：浏览器访问/accounts/paper/snapshots → read_paper_snapshots() → SQLite参数筛选demo_paper → fetchall得到两元组 → 每行组三字段字典并append → return列表。已接库，但首页还没有调用历史快照接口。
- 当前查询键为account_id/as_of/netvalue，金额字符串；页面paper标签与数据库demo_paper编号含义分别解释。print(rows)为调试输出，返回给浏览器的是records。
- data/dashboard.db由教师演示脚本创建，含accounts/snapshots/holdings；3份快照和虚构持仓。存在数据库时脚本保留已有文件。网站无真实券商、登录、模型、VPS或导入功能。
